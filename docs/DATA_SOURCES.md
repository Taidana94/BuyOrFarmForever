# Data sources

The addon ships game data only in `Data/ClassicEra/` (since 0.8.0). It applies to Classic Era only and must
not be reused for Forever without verification (CLAUDE.md section 4).

## Game data (Classic Era)

| Data | File | Source | Date | Status |
|---|---|---|---|---|
| Profession skill line ids (171, 164, 333, 202, 165, 197, 186, 185, 129, 40) and profession spell ids (2259, 2018, 7411, 4036, 2108, 3908, 2575, 2656 Smelting, 2550, 3273, 2842) | `Data/ClassicEra/Professions.lua` | Wowhead Classic skill pages and tooltip endpoint (`nether.wowhead.com/classic/tooltip/spell/<id>`) | 2026-10-23 | community; names compared at runtime with the client's own names, so a wrong id only means "Sonstige"; in-game check pending |
| Profession tools never suggested for selling (12 item ids) | `Data/ClassicEra/Tools.lua` | enchanting rods and engineering tools from `work/research/wowhead-crafted.json`; Flint and Tinder 4471, Mining Pick 2901, Skinning Knife 7005, Blacksmith Hammer 5956, Fishing Pole 6256 from general knowledge | 2026-10-24 | rods/tools: community data; the five others **unverified** (a wrong id only means one item is never suggested for selling) |
| Profession that makes an item (1372 crafted items, item id → profession key; 3 items made by two professions) | `Data/ClassicEra/CraftedBy.lua` | generated from `work/research/wowhead-crafted.json` (crafted-items listviews of the Wowhead Classic skill pages, `work/tools/wowhead_lists.py`) | 2026-10-23 | community; only names the profession in the item tooltip; not verified item by item |
| Effect categories of 205 crafted consumables and 153 enchantments (item / spell id → category) | `Data/ClassicEra/EffectData.lua` | generated by `work/tools/wowhead_buffs.py`: crafted items of the Wowhead Classic skill pages (`work/tools/wowhead_lists.py`), English tooltip text classified by rules (stats first, then regeneration, attack/spell power, armor, resistances, ...); classification reviewed by hand 2026-10-23 | 2026-10-23 | community data, rule-based; not verified item by item in game. Refresh: re-run both tools (cached tooltips in `work/research/wowhead/tooltips/`, delete them to re-fetch) and
review `work/research/wowhead-effects.json` before replacing the data file.
